TailCopy 0.2.4 runs on Linux desktops that use X11, and names devices after their
Tailscale machine name. Install it over 0.2.3; your history is kept.

## Download

| System | File |
| --- | --- |
| Windows 10 (22H2) and 11, x64 | `TailCopy-0.2.4-windows-x64-setup.exe` |
| macOS 13 and later, Apple silicon and Intel | `TailCopy-0.2.4-macos-universal.dmg` |
| Ubuntu 24.04 and 26.04, GNOME on Wayland | `TailCopy-0.2.4-ubuntu-amd64.deb` (includes the GNOME extension) |
| Other Linux desktops on X11, based on Ubuntu 24.04 (best effort) | the same `.deb` |

Check downloads against `SHA256SUMS`.

## New

- **X11 sessions on Linux.** On an X11 desktop (Zorin OS, Linux Mint, Pop!_OS, or GNOME
  on X11, which NVIDIA machines often get), TailCopy now captures copies, opens the
  picker from your shortcut and pastes back into the app you were using. It doesn't
  need the GNOME extension. The one `.deb` covers both: TailCopy picks the right way to
  work when it starts. Passwords that password managers mark as secret are skipped, as
  on GNOME.
- **A shortcut that's already taken is reported.** If another app holds your shortcut,
  TailCopy now tells you and asks you to choose another in Settings, on every system,
  instead of the shortcut silently doing nothing.

## Fixed

- **Device names.** A device is now named after its machine name on your tailnet (the
  name in the Tailscale admin console) instead of its OS hostname, which could differ
  or be shared by two machines. A name you set in Settings is kept.
- **Picker position.** The picker no longer opens off centre the first time.
- **Unsupported desktops.** Settings now says which desktop it found and which are
  supported.

If you're on 0.2.3, TailCopy tells you about this update by itself.
