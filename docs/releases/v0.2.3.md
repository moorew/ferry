TailCopy 0.2.3 fixes the picker's corners on Windows. Install it over 0.2.2; your
history is kept.

## Download

| System | File |
| --- | --- |
| Windows 10 (22H2) and 11, x64 | `TailCopy-0.2.3-windows-x64-setup.exe` |
| macOS 13 and later, Apple silicon and Intel | `TailCopy-0.2.3-macos-universal.dmg` |
| Ubuntu 24.04 and 26.04, GNOME on Wayland | `TailCopy-0.2.3-ubuntu-amd64.deb` (includes the GNOME extension) |

Check downloads against `SHA256SUMS`.

## Fixed

- **Picker corners on Windows.** Windows drew a square border and shadow around the
  rounded picker, leaving pale corners. Windows 11 now rounds the picker window
  itself, border and shadow included. Windows 10 shows it with square corners.

If you're on 0.2.2, TailCopy tells you about this update by itself.
